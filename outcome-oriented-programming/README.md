# Outcome-Oriented Programming
## From Applications to Agentic Execution

**Author and Original Creator:** Nicola Gallo  
**Publisher / Economic Copyright Holder / Licensor:** Nitro Agility S.r.l.

## Abstract

Outcome-Oriented Programming explores a shift from application-centric software to agentic execution.

Instead of requiring every workflow to be designed and deployed in advance, a user expresses an intent and a desired outcome. AI interprets that intent, constructs an execution plan, and composes reusable tools capable of producing the requested result.

The book argues that unrestricted runtime generation is not a sufficient production architecture because of latency, cost, correctness, security, governance, and compliance constraints. It therefore proposes a verifier-oriented model in which semantic tool contracts constrain software behavior, PIC constrains the authority of an execution lineage, and governance evaluates the residual risk before execution is allowed to continue.

In compact form:

**Intent → Outcome → Semantic Interpretation → Execution Plan → Tools → Verified Execution → Evidence → Governance → Outcome**

The central thesis is:

> Intelligence proposes.  
> Deterministic software executes.  
> Verification constrains behavior.  
> PIC constrains authority.  
> Governance decides whether residual risk is acceptable.
