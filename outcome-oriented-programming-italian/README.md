# Outcome-Oriented Programming
## Dalle applicazioni all'esecuzione agentica

**Autore e ideatore originale:** Nicola Gallo  
**Editore / Titolare dei diritti economici / Licenziante:** Nitro Agility S.r.l.

## Abstract

Outcome-Oriented Programming esplora il passaggio da un software centrato sulle applicazioni a un modello di esecuzione agentica.

Invece di richiedere che ogni workflow sia progettato e distribuito in anticipo, l'utente esprime un'intenzione e un risultato desiderato. L'AI interpreta tale intenzione, costruisce un piano di esecuzione e compone strumenti riutilizzabili in grado di produrre il risultato richiesto.

Il libro sostiene che la generazione a runtime senza vincoli non costituisce un'architettura di produzione sufficiente, a causa di limiti di latenza, costo, correttezza, sicurezza, governance e conformità. Propone quindi un modello orientato alla verifica, in cui i contratti semantici degli strumenti vincolano il comportamento del software, il PIC vincola l'autorità di una lineage di esecuzione e la governance valuta il rischio residuo prima di consentire il proseguimento dell'esecuzione.

In forma compatta:

**Intenzione → Risultato → Interpretazione semantica → Piano di esecuzione → Strumenti → Esecuzione verificata → Evidenze → Governance → Risultato**

La tesi centrale è:

> L'intelligenza propone.  
> Il software deterministico esegue.  
> La verifica vincola il comportamento.  
> Il PIC vincola l'autorità.  
> La governance decide se il rischio residuo è accettabile.
